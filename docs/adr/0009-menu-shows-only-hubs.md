# The command menu shows only Hubs; the old commands still work when typed

The menu had grown to 9 commands for Users and 12 for the Admin, enough that finding one meant scrolling on a phone. The menu now lists only the Hubs (/request, /tickets, /account, /help, plus /admin for the Admin). Each Hub opens one message of buttons for its area. Every command that left the menu still runs when typed, including shortcuts that take an argument, such as an Invite with the email given inline, so habits and docs that name them keep working.

## Considered Options

- One /menu home screen holding everything: fewest menu entries, but one extra tap before every action.
- Keep all commands and reorder them by use: least change, and the scrolling stays.
