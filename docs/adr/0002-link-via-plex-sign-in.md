# Link users through Plex sign-in, and call Seerr as them

A Link is made by the User signing in to Plex with a PIN, not by typing a username. Usher then calls Seerr as that User, so Tickets and Requests are attributed to the right Seerr account. Earlier versions identified the reporter by a name prefix in the ticket body and by a username typed to /link. Both were replaced because Seerr could not attribute the ticket to the user from them.
