# Settings and backups from before the rename load until 1.0.0

The project was renamed to Usher. Environment variable names, settings keys and backups from the former name are still read and translated, so existing installs keep working after the upgrade. Session cookies were renamed, so everyone signs in again once. This compatibility ends at 1.0.0: from then on, settings and backups from the former name no longer load, and the 1.0.0 release notes must warn upgraders.
